# Portfólio — exercício Alura

Repositório de um projeto de portfólio em HTML e CSS armazenado dentro da pasta `Projeto Alura/`. Contém páginas inicial e sobre, estilos e imagens.

## Estrutura

- `Projeto Alura/index.html`: página inicial dentro da subpasta.
- Arquivos HTML adicionais: páginas internas, quando presentes.
- Pastas de estilos, scripts e imagens: apresentação e recursos visuais.

## Como executar

Abra o projeto no VS Code e visualize o arquivo HTML indicado com Live Server ou diretamente no navegador.

```bash
git clone https://github.com/Pedro-Bonelli/portfolio.git
cd portfolio
```

Ponto de entrada: `Projeto Alura/index.html`. Não há etapa de instalação de pacotes na raiz.

## Observações

Ao abrir localmente, entre na subpasta `Projeto Alura/`; a raiz do repositório não contém `index.html`.
